## 🎨 Технические улучшения

### Удаление дублирования кода
- Убраны повторяющиеся статистические карточки
- Оптимизирован импорт компонентов
- Улучшена читаемость кода

### Система навигации
- React Router используется для передачи данных между компонентами
- State передается через `location.state`
- URL параметры для SEO-friendly ссылок

### Fallback система
- Если PNG изображение не найдено → показывается эмодзи
- Обработка ошибок через `onError` хендлеры
- Graceful degradation для лучшего UX

### Анимации
- Motion/React используется для плавных переходов
- Staggered animations для карточек достижений
- Hover эффекты на всех интерактивных элементах

## 🚀 Как использовать

### 1. Просмотр профилей команды
1. Перейдите на главную страницу (`/home`)
2. Прокрутите вниз до секции "🤠 Команда Банды"
3. Кликните на любую карточку персонажа
4. Откроется детальный профиль с информацией

### 2. Прохождение обучения с персонажами
1. На главной странице нажмите на баннер "Пройдите обучение"
2. Каждую главу ведет свой персонаж RDR2
3. Используйте стрелки для навигации между главами
4. Персонажи говорят от первого лица

### 3. Добавление PNG изображений
1. Поместите PNG файлы в `/public/characters/`
2. Имена файлов: `arthur-morgan.png`, `dutch-van-der-linde.png`, и т.д.
3. Рекомендуемый размер: 400x400px, квадрат
4. Обновите страницу (Ctrl+F5)
