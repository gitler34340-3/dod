## 🚀 Быстрый старт

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

### За 2 минуты

1. Откройте http://localhost:5173
2. Войдите (любой email/пароль - мок-авторизация)
3. Переключите тему (луна/солнце в правом верхнем углу)
4. Исследуйте дашборд с графиками и зарплатой

**[⚡ Полный быстрый старт →](./QUICKSTART.md)**

## 📱 Основные экраны

### 1. 🔐 Авторизация
Атмосферный экран входа с эффектами пыли и переключателем темы

### 2. 🏠 Дашборд (Главная)
- **Блок зарплаты** с графиком и переключением периодов
- **Быстрая статистика** (4 кликабельные карточки)
- **Ближайшие смены** с цветовой индикацией
- **Графики** распределения смен и KPI
- **Уведомления** с выпадающим меню
- **Баннер обучения** (если не пройдено)

### 3. 📅 Улучшенная страница смен
- **Планирование** новых смен (черновик→утверждение)
- **Обмен** сменами с коллегами
- **5 статусов**: Подтверждено, На рассмотрении, Черновик, Отклонено, Конфликт
- **Быстрая статистика** по статусам
- **Два режима**: Список (готов), Календарь (в разработке)

### 4. 👤 Личный кабинет (Новое!)
- **Профильная карточка** с полной информацией
- **Вкладка "Обзор"** - сводка достижений и документов
- **Вкладка "Документы"** - все кадровые файлы
- **Вкладка "Достижения"** - с выбором публичности
- **Вкладка "Обучение"** - пройденные курсы

### 5. 📄 Документы
Фильтры, поиск, статусы

### 6. 🏆 Достижения
3 уровня редкости, glow эффекты, прогресс

### 7. 📚 Обучение (Story)
5 глав, свайпы, автоматическое скрытие после прохождения

      - DodoLogo.tsx
      /ui                        # Radix UI компоненты
    /contexts

  /styles
