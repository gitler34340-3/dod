## 🐛 Типичные проблемы и решения

### Проблема: Карточки персонажей не кликаются
**Решение:** Проверьте консоль браузера на ошибки. Обновите страницу Ctrl+F5.

### Проблема: Профиль не открывается
**Решение:** Убедитесь что маршрут `/team/:memberName` добавлен в routes.tsx.

### Проблема: Изображения не загружаются
**Решение:** 
1. Проверьте что PNG файлы в `/public/characters/`
2. Проверьте имена файлов (должны быть с дефисами, не пробелами)
3. Обновите кеш браузера (Ctrl+F5)

### Проблема: Обучение показывает старые эмодзи вместо персонажей
**Решение:** Очистите localStorage и обновите страницу.

### Проблема: Анимации тормозят
**Решение:** Проверьте что motion/react установлен корректно. Откройте консоль.

### Проблема: Нет данных в профиле
**Решение:** Данные передаются через React Router state. Убедитесь что переход идет с главной страницы через клик на карточку.
