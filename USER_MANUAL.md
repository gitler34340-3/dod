# 🤠 Dodo Pizza Staff Management - RDR2 Edition

![Version](https://img.shields.io/badge/version-2.0-red)
![React](https://img.shields.io/badge/React-18-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Полностью переработанное веб-приложение для управления работой сотрудников в брутальной стилистике Red Dead Redemption 2. Современный UX/UI встречается с атмосферой Дикого Запада.

---

## 🎯 Что нового в версии 2.0

### ✨ Новые функции

- ✅ **Переключение тем** - Тёмная (по умолчанию) и светлая (пергамент) темы
- ✅ **Чёрно-красная палитра** - Брутальный дизайн с кроваво-красными акцентами
- ✅ **Блок зарплаты** - Интерактивный виджет с переключением периодов (день/неделя/месяц/год/всё время)
- ✅ **Chart.js графики** - Динамика зарплаты, распределение смен, KPI
- ✅ **Улучшенные смены** - Планирование, обмен, статусы (черновик→рассмотрение→утверждение/отклонение)
- ✅ **Личный кабинет** - Полный профиль с документами, ачивками, обучением
- ✅ **Умное обучение** - После прохождения исчезает с главной, доступно в профиле
- ✅ **Интерактивная статистика** - Кликабельные карточки с детальной информацией

### 🎨 Улучшения дизайна

- Glassmorphism эффекты с эффектом матового стекла
- Красное свечение при наведении (hover-red-glow)
- Плавные микроанимации с Motion/React
- Текстуры пергамента в светлой теме
- Responsive дизайн для всех устройств

## 🚀 Быстрый старт

### Требования

- Node.js 18+
- npm или pnpm

### Установка

\`\`\`bash
# Клонирование репозитория
git clone <repo-url>

# Переход в директорию
cd dodo-rdr2-staff

# Установка зависимостей
npm install
# или
pnpm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
\`\`\`

### Первый запуск

1. Откройте приложение в браузере (обычно http://localhost:5173)
2. На странице входа используйте любой email/пароль (мок-авторизация)
3. Попробуйте переключить тему в правом верхнем углу
4. Пройдите обучение или пропустите его
5. Исследуйте дашборд и все страницы!

## 📖 Руководство по использованию

### 🏠 Главная страница (Дашборд)

**Расположение**: `/home`

Центральный хаб приложения с ключевой информацией:

1. **Шапка**:
   - Клик по аватару → переход в профиль
   - Переключатель темы (луна/солнце)
   - Уведомления с индикатором
   - Кнопка профиля

2. **Баннер обучения** (если не пройдено):
   - Отображается только до завершения
   - Клик → переход к обучению
   - После прохождения исчезает автоматически

3. **Быстрая статистика** (4 карточки):
   - Ближайшие смены → переход на `/schedule`
   - KPI недели (интерактивная)
   - Новые ачивки → переход на `/achievements`
   - Документы → переход на `/documents`

4. **Блок зарплаты** (большой):
   - Выбор периода: день/неделя/месяц/год/всё время
   - Интерактивный график с Chart.js
   - Индикатор роста/падения
   - Wanted poster стилистика

5. **Ближайшие смены** (боковая панель):
   - Список предстоящих смен
   - Цветовые индикаторы статуса:
     - ✅ Зелёный = подтверждено
     - ⏳ Жёлтый = ожидает
   - Клик → полный график смен

6. **Графики аналитики**:
   - **Распределение смен** (круговая диаграмма):
     - Утренние / дневные / вечерние / ночные
   - **KPI за неделю** (столбчатая диаграмма):
     - Выполненные задачи
     - KPI балл по дням

### 📅 Страница смен

**Расположение**: `/schedule`

Полное управление графиком работы:

1. **Создание новой смены**:
   - Кнопка "Предложить смену" (правый верхний угол)
   - Выбор даты и времени
   - Создаётся как черновик
   - Отправка на утверждение менеджеру

2. **Статусы смен**:
   - 📝 **Черновик** (серый) - можно редактировать, кнопка "Отправить"
   - ⏳ **На рассмотрении** (жёлтый) - ждём ответа менеджера
   - ✅ **Подтверждено** (зелёный) - смена одобрена, кнопка "Обменять"
   - ❌ **Отклонено** (красный) - смена не одобрена
   - ⚠️ **Конфликт** (красный) - пересечение с другой сменой

3. **Обмен сменами**:
   - Доступно для подтверждённых смен
   - Кнопка "Обменять" на карточке
   - Запрос отправляется коллегам
   - Уведомление о результате

4. **Статистика**:
   - Подтверждённых
   - На рассмотрении
   - Черновиков
   - Всего смен

5. **Режимы просмотра**:
   - **Список** (реализован) - детальные карточки
   - **Календарь** (в разработке) - визуализация

### 👤 Личный кабинет

**Расположение**: `/profile`

Ваш персональный центр:

1. **Профильная карточка**:
   - Аватар с звездой уровня
   - Полная информация:
     - Email, телефон
     - Адрес
     - Дата начала работы
     - Стаж
     - Рейтинг
   - Статистика в нижней части:
     - Отработано смен
     - Средний KPI
     - Собрано ачивок
     - Пройдено курсов

2. **Вкладка "Обзор"**:
   - Последние достижения (3)
   - Активные документы

3. **Вкладка "Документы"**:
   - Все кадровые документы
   - Фильтр по статусу:
     - Активные (зелёный)
     - Ожидают (жёлтый)
     - Архив (серый)
   - Клик → просмотр документа

4. **Вкладка "Достижения"**:
   - Все разблокированные ачивки
   - Редкость с цветами:
     - 🌟 Обычное (зелёный)
     - 💜 Редкое (фиолетовый)
     - 🔥 Легендарное (красный с glow)
   - Звёздочка → публичность достижения
   - Прогресс выполнения

5. **Вкладка "Обучение"**:
   - Завершённые модули
   - Оценки (из 100)
   - Даты прохождения
   - Кнопка "Пройти снова" (если доступно)

6. **Кнопка выхода**:
   - Внизу страницы
   - Возврат на страницу входа

### 📖 Обучение (Story)

**Расположение**: `/story`

Интерактивное обучение:

1. **Навигация**:
   - Стрелки влево/вправо
   - Свайпы на мобильных
   - Прогресс-бар вверху
   - Счётчик внизу (1/5, 2/5...)

2. **5 глав**:
   - Добро пожаловать, Ковбой!
   - Искусство Пиццы
   - Работа в Команде
   - Обслуживание Гостей
   - Путь к Мастерству

3. **После завершения**:
   - Автоматически помечается как пройденное
   - Исчезает с главной страницы
   - Доступно в профиле для повтора

4. **Кнопка закрытия**:
   - Правый верхний угол
   - Возврат на главную

### 🏆 Достижения

**Расположение**: `/achievements`

Все ваши ачивки и прогресс.

### 📄 Документы

**Расположение**: `/documents`

Кадровая документация с фильтрами.

## 🎨 Переключение темы

### Тёмная тема (по умолчанию)

- Глубокий чёрный фон (#0f0f0f)
- Кроваво-красные акценты (#c1121f)
- Приглушённый оранжевый для вторичных элементов
- Идеально для работы вечером/ночью

### Светлая тема

- Выцветший пергамент (#f5e6d3)
- Тёплые сепия-тона
- Сохранены красные акценты
- Текстуры бумаги и ткани
- Идеально для дневной работы

**Как переключить**:
1. Найдите иконку луны/солнца в правом верхнем углу
2. Кликните на неё
3. Тема изменится с плавной анимацией
4. Выбор сохраняется автоматически

## 📊 Графики и аналитика

### График зарплаты

- **Период "День"**: Почасовой график (00:00 - 24:00)
- **Период "Неделя"**: По дням недели (Пн-Вс)
- **Период "Месяц"**: По неделям (1-4)
- **Период "Год"**: По месяцам (Янв-Дек)
- **Период "Всё время"**: По годам/кварталам

**Интерактивность**:
- Наведение → tooltip с точной суммой
- Плавные анимации при переключении

### Распределение смен

Круговая диаграмма с типами смен:
- Утренние (08:00-16:00)
- Дневные (14:00-22:00)
- Вечерние (16:00-00:00)
- Ночные (22:00-06:00)

### KPI

Столбчатая диаграмма:
- Синие столбцы = выполненные задачи
- Оранжевые столбцы = KPI балл
- По дням недели

## 🛠 Технические детали

### Стек технологий

- **Frontend**: React 18.3.1 + TypeScript
- **Маршрутизация**: React Router 7
- **Стилизация**: Tailwind CSS v4
- **Анимации**: Motion/React (Framer Motion)
- **Графики**: Chart.js + react-chartjs-2
- **Иконки**: Lucide React
- **UI Components**: Radix UI
- **Сборка**: Vite 6

### Структура

\`\`\`
src/
├── app/
│   ├── components/
│   │   ├── charts/                    # Графики
│   │   │   ├── SalaryChart.tsx
│   │   │   ├── ShiftsDistributionChart.tsx
│   │   │   └── KPIChart.tsx
│   │   ├── DashboardScreen.tsx        # Главная
│   │   ├── ProfileScreen.tsx          # Профиль
│   │   ├── ImprovedScheduleScreen.tsx # Смены
│   │   ├── StoryScreen.tsx            # Обучение
│   │   ├── ThemeToggle.tsx            # Переключатель темы
│   │   └── ...
│   ├── contexts/
│   │   └── ThemeContext.tsx           # Контекст темы
│   └── routes.ts                      # Маршруты
├── styles/
│   ├── rdr2-theme.css                 # CSS переменные и темы
│   └── fonts.css                      # Шрифты
└── ...
\`\`\`

### CSS Переменные

Все переменные в `/src/styles/rdr2-theme.css`:

\`\`\`css
/* Тёмная тема */
--bg-primary: #0f0f0f;
--accent-primary: #c1121f;
--text-primary: #ffffff;

/* Светлая тема */
[data-theme="light"] {
  --bg-primary: #f5e6d3;
  --accent-primary: #a01010;
  --text-primary: #2c1810;
}
\`\`\`

## 🐛 Известные проблемы и ограничения

1. **Календарный вид смен** - в разработке (показывается заглушка)

4. **Обмен сменами** - UI готов, логика требует бэкенда
