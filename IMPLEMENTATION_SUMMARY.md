## 🚀 Как добавить PNG картинки

### Быстрый способ:
1. Скачайте PNG изображения персонажей RDR2
2. Переименуйте в формат: `имя-персонажа.png` (строчные буквы, дефисы)
3. Поместите в папку `/public/characters/`
4. Готово! Изображения загрузятся автоматически

### Пример:
```bash
/public/characters/
├── arthur-morgan.png          # ✅ Правильно
├── dutch-van-der-linde.png    # ✅ Правильно
└── John Marston.PNG            # ❌ Неправильно (заглавные буквы)
```

## 🎨 Технические детали

### Структура компонента
```tsx
<CharacterCard
  name="Arthur Morgan"           // Имя персонажа
  role="Главный стрелок"         // Роль в банде
  color="var(--accent-primary)"  // Цвет темы
  index={0}                      // Индекс для анимации
/>
```

### Автоматический путь к изображению
```tsx
// Имя: "Arthur Morgan"
// Генерируется путь: "/characters/arthur-morgan.png"

const imagePath = `/characters/${name.toLowerCase().replace(/\s+/g, '-')}.png`;
```

### Fallback логика
```tsx
<img 
  src={imagePath}
  onError={() => setImageError(true)} // Если ошибка → показать 🤠
/>
```

## 📱 Адаптивность

### Сетка персонажей:
- **Мобильные** (< 768px): 2 колонки
- **Планшеты** (768px - 1024px): 3 колонки
- **Десктоп** (> 1024px): 6 колонок

### Анимации:
- Появление с задержкой (stagger effect)
- Hover: scale(1.05) + подъём вверх
- Пульсация индикатора активности
- Плавное увеличение изображения при hover
