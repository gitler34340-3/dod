# 🤠 Руководство пользователя - Dodo Staff (Wild West Edition)

Добро пожаловать в уникальное приложение для управления персоналом Dodo Pizza, выполненное в стиле Red Dead Redemption 2!

## 🎮 Начало работы

### Вход в приложение

1. Откройте приложение - вы увидите атмосферный экран входа с пыльными эффектами Дикого Запада
2. Введите ваш Email и пароль
3. Нажмите кнопку **"Войти в Wild West"**
4. Наслаждайтесь анимациями входа!

> **Примечание**: Сейчас приложение работает в демо-режиме - любой email и пароль откроют доступ

## 🏠 Главный экран (Home)

После входа вы попадёте на главный экран с:

### Ваш профиль
- **Аватар Артура Моргана** 🤠 - ваш персонаж в стиле RDR2
- Ваше имя и должность

### Меню навигации
На главном экране доступны 4 основных раздела:

#### 📅 Смены
Управление вашим графиком работы

#### 📄 Документы
Кадровые документы и файлы

#### 🏆 Ачивки
Ваши достижения и прогресс

#### 📚 Обучение
Story-режим для обучения новым навыкам

### Быстрая статистика
В нижней части экрана вы увидите:
- Количество предстоящих смен
- Количество разблокированных ачивок
- Количество документов

## 📅 Экран смен (Schedule)

### Просмотр смен
- Листайте список ваших смен вверх-вниз
- Каждая смена имеет **цветовую индикацию**:
  - 🟢 **Зелёный** - смена подтверждена
  - 🟡 **Жёлтый** - смена ожидает подтверждения
  - 🔴 **Красный** - конфликт в расписании

### Информация о смене
Каждая карточка смены показывает:
- День недели и дату
- Время начала и окончания
- Локацию (адрес пиццерии)
- Вашу должность на смене

### Детали смены
- Нажмите на любую смену для просмотра подробностей
- Откроется модальное окно с полной информацией

### Запрос замены
Если вам нужна замена смены:
1. Найдите нужную смену
2. Нажмите кнопку **"Запросить замену"**
3. Подтвердите запрос
4. Ваши коллеги получат уведомление!

## 📄 Экран документов (Documents)

### Поиск документов
- Используйте поле поиска вверху экрана
- Введите название документа для быстрого поиска

### Фильтрация
Отфильтруйте документы по типу:
- Все документы
- Контракты
- Графики
- Инструкции
- Заявления
- Справки

### Статусы документов
- ✅ **Подписано** - документ уже подписан вами
- ⏳ **Требует подписи** - необходимо подписать
- 🔴 **Срочно** - красный бейдж для срочных документов

### Действия с документами
1. **Просмотр**: нажмите на документ для открытия
2. **Скачивание**: кнопка скачивания справа на карточке
3. **Подписание**: откройте документ и нажмите "Подписать"

## 🏆 Экран достижений (Achievements)

### Типы ачивок по редкости

#### 🟢 Обычные (Common)
- Базовые достижения
- Зелёное свечение
- Легко разблокировать

#### 🟣 Редкие (Rare)
- Более сложные задания
- Фиолетовое свечение
- Требуют больше усилий

#### 🟡 Легендарные (Legendary)
- Самые престижные достижения
- Золотое пульсирующее свечение
- Очень сложно получить!

### Прогресс достижений
- Неразблокированные ачивки показывают прогресс-бар
- Следите за своим прогрессом в режиме реального времени
- При достижении цели ачивка разблокируется автоматически!

### Steam-style уведомления
При разблокировке достижения:
- Появляется всплывающее уведомление в правом нижнем углу
- Показывает иконку и название ачивки
- Исчезает через несколько секунд

## 📚 Экран обучения (Story)

### Режим Story
Вертикальные истории в стиле Instagram Stories, но про Dodo Pizza!

### Навигация по историям
- ⬅️ **Кнопка "Назад"** - вернуться к предыдущей истории
- ⏸️ **Кнопка "Пауза"** - приостановить просмотр
- ▶️ **Кнопка "Играть"** - продолжить просмотр
- ➡️ **Кнопка "Далее"** - следующая история

### Прогресс-индикаторы
- Вверху экрана показаны индикаторы всех историй
- Текущая история подсвечивается красно-оранжевым градиентом
- Пройденные истории полностью заполнены

### Главы обучения
1. **Добро пожаловать, Ковбой!** - знакомство с Dodo Pizza
2. **Искусство Пиццы** - основы приготовления
3. **Работа в Команде** - командные навыки
4. **Обслуживание Гостей** - работа с клиентами
5. **Путь к Мастерству** - становление профессионалом

### Жесты
- Свайпайте влево/вправо для навигации (на мобильных)
- Нажмите ✖️ для выхода в любой момент

## 🎨 Особенности интерфейса

### Анимации
- Все элементы плавно появляются при загрузке
- Интерактивные элементы реагируют на наведение
- Micro-animations при взаимодействии

### Glassmorphism
- Полупрозрачные карточки с размытием
- Атмосферный эффект глубины
- Тонкие границы для элегантности

### Dust Effect (Эффект пыли)
- Анимированные частицы пыли на фоне
- Создаёт атмосферу Дикого Запада
- Постоянное движение для живости

### Градиенты
- Красно-оранжевые переходы везде
- Золотые акценты для легендарных элементов
- Тёмные фоны для контраста

## 🆘 Помощь и поддержка

### Частые вопросы

**Q: Почему мои данные не сохраняются?**
A: Сейчас приложение работает в демо-режиме с тестовыми данными. Для сохранения данных нужно подключить Supabase (см. SUPABASE_INTEGRATION.md)

**Q: Как получить легендарные ачивки?**
A: Выполняйте сложные задания и работайте на отлично! Легендарные ачивки требуют максимальных усилий.

**Q: Можно ли использовать на компьютере?**
A: Да! Приложение адаптивное и отлично работает как на мобильных, так и на десктопах.

**Q: Как работают анимации?**
A: Все анимации создаются с помощью Motion (Framer Motion) для плавного и приятного опыта.
