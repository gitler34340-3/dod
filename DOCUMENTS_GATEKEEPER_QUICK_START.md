## 🗄️ Три Таблицы (Упрощённо)

### 1. document_types (Типы)

```
ID | Name          | is_mandatory | validity_days
---|---------------|--------------|---------------
1  | Паспорт       | TRUE  🔐     | 3650 (10 лет)
2  | Медкнижка     | TRUE  🔐     | 365 (1 год)
3  | ДМС           | TRUE  🔐     | 365 (1 год)
4  | Сертификат    | FALSE        | 365 (1 год)
```

**Ключевое:** `is_mandatory = TRUE` → ГЕЙТКИПЕР! 🔐

### 2. employee_documents (Документы Сотрудников)

```
ID | Employee | Type_ID | Status      | Expiry_Date
---|----------|---------|-------------|-------------
A1 | emp-123  | 1       | active      | 2035-06-15
A2 | emp-123  | 2       | expired ❌  | 2024-01-10
A3 | emp-123  | 3       | pending ⏳  | 2026-03-30
```

**Ключевое:**
- `status = pending/rejected/expired` → БЛОКИРОВКА
- `status = active/approved` → ОК (только если не просрочена)

### 3. document_requests (Ордеры от Админа)

```
ID | Employee | Type_ID | Deadline   | Priority | Status
---|----------|---------|------------|----------|--------
R1 | emp-123  | 2       | 31.03.2026 | HIGH     | pending
```

**Ключевое:**
- Админ может "требовать" документ от сотрудника
- Сотрудник видит как срочный баннер
- После загрузки → на проверку админу

## 🛡️ Middleware Logic (Pseudo-code)

```javascript
function gatekeeper(req) {
  // 1. Получить ID сотрудника
  const employeeId = req.user.id;
  
  // 2. Это защищённый маршрут? (/shifts, /payroll, и т.д.)
  if (!isProtectedRoute(req.path)) {
    return next(); // Пропустить, не защищено
  }
  
  // 3. Получить все ОБЯЗАТЕЛЬНЫЕ типы документов
  const mandatoryTypes = DB.select('document_types WHERE is_mandatory = true');
  
  // 4. Для каждого обязательного типа:
  for (type of mandatoryTypes) {
    doc = DB.select('employee_documents WHERE employee_id = ? AND type_id = ?', [employeeId, type.id]);
    
    // 5. Есть ли документ?
    if (!doc) {
      return 403 with message "Требуется: " + type.name;
    }
    
    // 6. Статус ОК?
    if (doc.status != 'active' AND doc.status != 'approved') {
      return 403 with message "Требуется: " + type.name + " (" + doc.status + ")";
    }
    
    // 7. Не истёк ли срок?
    if (doc.expiry_date < now()) {
      return 403 with message "Требуется: " + type.name + " (EXPIRED)";
    }
  }
  
  // 8. Все документы в норме!
  return next(); // Пропустить дальше
}
```

## 💻 На Каких Уровнях Это Работает?

1. **Database Level** (PostgreSQL)
   - Таблицы: document_types, employee_documents, document_requests, gatekeeper_logs

2. **Backend Level** (NestJS)
   - Middleware: GatekeeperMiddleware
   - Services: DocumentsService, DocumentRequestsService
   - Controllers: REST endpoints

3. **Frontend Level** (React)
   - Context: GatekeeperContext
   - Components: GatekeeperBlockscreen, DocumentRequestBanner
   - Interceptors: Axios перехватывает 403

4. **Network Level** (HTTP)
   - Middleware возвращает 403 с кодом error: "GATEKEEPER_BLOCKED"

## ❓ FAQ

**Q: Можно ли обойти гейткипер, изменив URL?**
A: Нет! Middleware срабатывает для ВСЕХ запросов на protected routes.

**Q: Что если документ просроченный, но админ забыл обновить?**
A: Автоматически блокируется по expiry_date (сравнивается с NOW()).

**Q: Можно ли запросить разные документы от разных сотрудников?**
A: Да! Ордер (request) — это сотрудник + тип документа + дедлайн. Каждый может быть уникален.

**Q: Как сотрудник узнаёт о просроченном документе?**
A: Либо видит GatekeeperBlockscreen, либо администратор отправляет ордер (баннер).

**Q: Что логируется в gatekeeper_logs?**
A: Каждый успешный доступ и каждая блокировка (для аудита).
