# Dodo Pizza Staff Management - RDR2 Edition

## 🤠 Описание проекта

Инновационное приложение для управления персоналом и кадровыми документами Dodo Pizza, выполненное в уникальной эстетике Red Dead Redemption 2. Приложение сочетает в себе современный UX/UI с атмосферой Дикого Запада, создавая незабываемый пользовательский опыт.

## 🎨 Дизайн и стиль

### Цветовая палитра
- **Основной красный**: #d32f2f (RDR2 Red)
- **Оранжевый**: #ff6f00 (Dodo Orange)
- **Золотой**: #ffa000 (Wild West Gold)
- **Темно-коричневый**: #2c1810 (Western Brown)
- **Пыльный**: #d7ccc8 (Desert Dust)

### Градиенты
- Red-Orange: `linear-gradient(135deg, #d32f2f 0%, #ff6f00 100%)`
- Orange-Gold: `linear-gradient(135deg, #ff6f00 0%, #ffa000 100%)`
- Dark Background: `linear-gradient(180deg, #1a1a1a 0%, #2c1810 100%)`

### Типографика
- **Заголовки**: Playfair Display (serif) - для создания классического западного стиля
- **Основной текст**: Open Sans (sans-serif) - для читаемости

## 📱 Экраны приложения

### 1. LoginScreen (`/`)
- Атмосферный фон с эффектом пыли/дымки
- Логотип Dodo Pizza с анимацией
- Плавные анимации появления полей ввода
- Градиентная кнопка входа

### 2. HomeScreen (`/home`)
- Аватар Артура Моргана (Lottie-style)
- Горизонтальный свайпер с карточками меню (мобильная версия)
- Сетка карточек (десктоп)
- Быстрая статистика
- Уведомления

### 3. ScheduleScreen (`/schedule`)
- Календарь смен с цветовой индикацией:
  - 🟢 Зелёный - подтверждено
  - 🟡 Жёлтый - ожидание
  - 🔴 Красный - конфликт
- Горизонтальный и вертикальный свайп
- Модальные окна для деталей
- Функция "Запросить замену"

### 4. DocumentsScreen (`/documents`)
- Список PDF документов
- Поиск и фильтрация
- Кнопка "Подписать" с анимацией успеха
- Модальный просмотр документов
- Скачивание файлов

### 5. AchievementsScreen (`/achievements`)
- Карточки достижений с редкостью:
  - 🟢 Обычная (Common)
  - 🟣 Редкая (Rare)
  - 🟡 Легендарная (Legendary)
- Glow эффекты вокруг легендарных ачивок
- Анимации bounce/scale
- Steam-style popup при получении
- Прогресс-бар для незавершённых достижений

### 6. StoryScreen (`/story`)
- Вертикальные сторис с обучением
- Lottie-анимации персонажей
- Кнопки навигации (Далее/Назад/Пауза)
- Прогресс-индикаторы
- Плавные swipe анимации

## 🎭 Анимации и эффекты

### Glassmorphism
- Полупрозрачный фон с blur
- Использование `backdrop-filter: blur(10px)`
- Тонкие границы `rgba(255, 255, 255, 0.1)`

### Dust Effect
- Анимированные частицы пыли
- Радиальные градиенты для атмосферы
- Постоянное движение для создания эффекта живого мира

### Glow Effects
- Легендарные ачивки: золотое свечение
- Редкие ачивки: фиолетовое свечение
- Пульсирующая анимация

### Micro-animations
- Hover эффекты на кнопках и карточках
- Scale и rotate трансформации
- Плавные переходы цветов

## 🛠 Технологический стек

### Основные библиотеки
- **React 18.3.1** - UI фреймворк
- **React Router 7** - Навигация
- **Motion (Framer Motion)** - Анимации
- **Tailwind CSS v4** - Стилизация
- **Lucide React** - Иконки
- **React Slick** - Карусели

### UI компоненты
- Radix UI - для accessible компонентов
- Sonner - для toast уведомлений
- Custom компоненты в стиле RDR2
